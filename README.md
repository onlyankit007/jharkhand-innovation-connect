## Run

Keep:
- index.html
- styles.css
- app.js
- README.md

Open index.html or run it with VS Code Live Server.

## Current architecture

This is still a frontend MVP. New citizen challenges are stored in localStorage.

For the true multi-user production platform, connect this UI to Supabase/PostgreSQL and implement:
- secure authentication
- role based access control
- realtime subscriptions
- file storage
- server-side challenge ID generation
- AI categorization and matching
- duplicate detection
- verified institution registry
- audit trail
- notifications
- real analytics
